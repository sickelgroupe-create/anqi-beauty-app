# 暨美丽三端部署交付

## 访问入口

- 用户端：https://anqi.okam.top
- 若依后台：https://anqiht.okam.top
- 用户接口：https://anqiht.okam.top/api
- 若依管理接口：https://anqiht.okam.top/prod-api
- 后台管理员账号：`admin`。密码已按本次要求修改，并已验证实际登录。

两个站点均启用 HTTPS 和 HTTP 自动跳转。证书自动续期已配置。

## 三端数据关系

用户端和微信小程序请求若依 Java 接口入口。若依负责管理员登录、验证码、菜单、角色权限和操作日志；业务模块负责商品、会员、订单和预约等规则。业务数据统一存储于本项目独立 MySQL 数据库，未连接其他站点数据库。

若依后台通过受权限保护的接口调用业务模块，内部接口仅监听本机并使用独立密钥。没有在浏览器中保存数据库密码或内部密钥。

后台展示工作台和13个业务页面，分为日常业务和店铺设置。已隐藏系统管理、监控、开发工具及不需要独立操作的技术页面；收货地址随业务详情展示。

管理商品支持服务/实物、价格、疗程价、库存、上下架、首页推荐、贵宾/体验礼品及图片上传。会员支持资格管理、联系电话查看、停用与账号密码重置。订单支持取消、核实线下收款、物流/取货说明及核销。预约完成同步完成对应服务订单。礼品支持发放核销。

## 服务器运维

项目目录：`/opt/anqi`。

| 服务 | 用途 | 仅本机端口 |
|---|---|---|
| anqi-backend | 若依 Java 接口 | 8097 |
| anqi-business | 事务业务模块 | 3016 |
| anqi-mysql | 独立 MySQL | 3309 |
| anqi-redis | 若依缓存与登录会话 | 16382 |

四个服务均由 systemd 管理，配置开机启动和异常重启。站点文件在宝塔原目录 `/www/wwwroot/anqi.okam.top` 与 `/www/wwwroot/anqiht.okam.top`。

服务配置保存在 `/opt/anqi/shared`；该目录中的数据库密码、内部密钥和微信密钥不得作为网页文件发布。日志在 `/opt/anqi/logs`，也可通过 `journalctl -u anqi-backend` 或 `journalctl -u anqi-business` 查看。

每日03:20备份数据库与上传图片到 `/opt/anqi/backups`，保留最近7份。备份只保存在本服务器，未配置异地灾备。`anqi-backup.timer` 管理备份时间；`systemctl start anqi-backup.service` 可手动备份。首次部署前两个站点与 Nginx 配置已保存为 `initial-sites.tgz`。

数据库采用每种业务一张表保存 JSON 记录并包含会员、状态索引。业务写入通过数据库行锁和事务串行处理，避免超扣库存和重复处理订单。当前实现适用于单门店规模；尚未进行高并发压力测试。

## 源码和构建

- 前端及业务模块：桌面 `安琪美容/anqi-beauty-app`。
- 若依 Java 与后台 Vue3：桌面 `安琪美容/anqi-beauty-backend` 和 `安琪美容/anqi-beauty-backend3`。
- 前端 `.env.production` 指向正式后端域名。`npm run build:h5`、`npm run build:mp-weixin` 生成正式构建。
- 微信开发者工具导入 `dist/build/mp-weixin`。H5产物为 `dist/build/h5`。
- 若依 Vue3执行 `npm run build:prod`；Java执行 `mvn -DskipTests package`。
- 本地开发 `npm run dev:h5` 仍使用本地接口；本地演示数据与正式数据库分开。
